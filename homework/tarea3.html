Q3. Create a scatterplot showing the relationship between Girth and Volume.

head(trees[, c("Girth", "Volume")], 6)
##   Girth Volume
## 1   8.3   10.3
## 2   8.6   10.3
## 3   8.8   10.2
## 4  10.5   16.4
## 5  10.7   18.8
## 6  10.8   19.7
ggplot(trees, aes(x = Girth, y = Volume)) +
  geom_point(size = 2, color = "darkred") +
  geom_smooth(method = "lm", se = TRUE, color = "black") +  # linear trend line
  labs(title = "Relationship between Girth and Volume",
       x = "Girth (inches)",
       y = "Volume (cubic feet)") +
  theme_minimal()
## `geom_smooth()` using formula = 'y ~ x'

The relationship for this plot is very strong; the greater value is seen where trees have a larger girth.

Q4. Use the Shapiro–Wilk test to assess whether Volume is normally distributed. Report the p-value and state whether the data are normally distributed.

shapiro_volume <- shapiro.test(trees$Volume)
shapiro_volume
## 
##  Shapiro-Wilk normality test
## 
## data:  trees$Volume
## W = 0.88757, p-value = 0.003579
# Extract the p-value
shapiro_volume$p.value
## [1] 0.003578866
##  Shapiro-Wilk normality test
## data:  trees$Volume
## W = 0.88757, p-value = 0.003579

It’s less than 0.05, so the p-value is about 0.0036. That’s why we don’t accept the null hypothesis of normality: Volume is not spread out properly. See how this lines up with the right shift in the Q2 histogram?

Q5. Repeat the Shapiro–Wilk test for Girth. Report the p-value and state whether Girth is normally distributed.

shapiro_girth <- shapiro.test(trees$Girth)
shapiro_girth
## 
##  Shapiro-Wilk normality test
## 
## data:  trees$Girth
## W = 0.94117, p-value = 0.08893
shapiro_girth$p.value
## [1] 0.08893018

The p-value is higher than 0.05, at roughly 0.089. Since there is no substantial evidence that Girth deviates from normalcy and may be regarded as roughly normally distributed, we are unable to reject the null hypothesis.
